# Каталог сессий и прокрутка файлов — 2026-11-07

Исправлены медленное обновление каталога Codex и общая прокрутка дерева с открытым файлом.
Изменения подготовлены локально; сервер и работающий Windows-мост ещё не обновлялись.

## Причина задержки каталога

Мост ограничивал чтение каждого движка восемью секундами. Обычный `thread/list`
дополнительно сканирует JSONL-журналы для восстановления метаданных; это поведение и режим
`useStateDbOnly` описаны в [официальной документации OpenAI](https://learn.chatgpt.com/docs/app-server#list-threads-with-pagination--filters).
Именно этот запрос, а не запуск процесса, занимал секунды. Ожидание общего mutex метаданных
добавлялось к сроку; отмена чтения сбрасывала общий RPC. Браузер получал `complete: false`
и сохранял прежний список с предупреждением.

Первое измерение: подключение 0,263 с, каталог Studio 8,324 с при лимите 8 с.
Проверены CLI 0.162.0-alpha.2 и установленный 0.167.0-alpha.3.2: обычный каталог медленный в обоих.
Смена регистра диска, канонический Windows-путь и меньшая страница проблему не устранили.

Повторное сравнение обычного запроса и `useStateDbOnly: true` в одном процессе:

| Проект | Обычный запрос | Готовый индекс | Сессий до / после | Наборы ID |
| --- | ---: | ---: | ---: | --- |
| Studio | 14,9677 с | 0,0314 с | 58 / 58 | совпали |
| Контрольный проект | 16,1677 с | 0,0564 с | 27 / 27 | совпали |

Проверка изменённого `CodexRunner.chats`: первый вызов вместе с запуском процесса —
0,7693 с (58 сессий), следующий проект — 0,0544 с (27 сессий).

Мост 0.14.1 читает каталог штатным RPC с `useStateDbOnly: true`, без прямого чтения или
изменения базы Codex. Срок ответа остаётся 8 с; общее чтение может закончиться в фоне за 30 с
и заполнить прежний RAM-кэш. Проверки PIN и свежая активность Runner сохранены.
Диагностика обращалась только к метаданным, без генерации; тексты и ID сессий в отчёт не записаны.

## Прокрутка файлов

Активный раздел файлов занимает доступную высоту рабочей области. Дерево и открытый файл
расположены в отдельной сетке и прокручиваются независимо; редактор имеет собственную прокрутку.
На телефоне дерево скрыто при открытом файле, возврат сохраняет его позицию.
Общая прокрутка чатов и остальных разделов не менялась.
