# Глоссарий названий интерфейса

Источник слов для README, страницы входа, manifest, push и текстов разделов. Новый текст берёт название из
столбца «Название». В коде имена, значки и порядок разделов — один реестр `app/static/js/sections-meta.js`
(значки — `app/static/js/icons.js`); сервер (`sections.NAMES`, `push.TITLE`) сверяет `tests/test_sections_meta.py`.

## Приложение

| Где | Сейчас | Файл |
|---|---|---|
| Название | **Студия** (в тексте README — «студия») | — |
| manifest `name` / `short_name` | Студия | `app/static/manifest.webmanifest` |
| manifest `description` | «Чат, агенты, фото, видео, разговоры, озвучка, сканы и перевод» | `app/static/manifest.webmanifest` |

## Разделы

Порядок — группами (на рельсе тонкий разделитель): Чат, Агенты · Фото, Видео · Разговоры, Озвучка · Сканы, Перевод.
Тот же порядок — в нижней панели телефона (по умолчанию Чат, Агенты, Фото и «Ещё»), в «Поиске», блокировке, выгрузке и
настройках. id раздела и адрес не меняются вместе с именем (`#/speech` — «Озвучка»).

| id (адрес, API) | Название | Значок (`icons.js`) | Где ещё |
|---|---|---|---|
| `chat` | Чат | облачко | |
| `code` (`#/code`, `/api/code/*`) | Агенты | приглашение терминала | выгрузка: «Агенты: чаты», «Агенты: подключения» |
| `photo` | Фото | картинка | |
| `video` | Видео | кадр с треугольником | |
| `transcribe` | Разговоры | звуковая волна | действие в «В работе» — «Расшифровка «…»» |
| `speech` | Озвучка | динамик | действие в «В работе» — «Озвучка · …» |
| `ocr` | Сканы | рамка с строками | действие в «В работе» — «Распознавание «…»» (действие, не имя раздела) |
| `translate` | Перевод | буквы двух языков | |
| `dictation` | Голосовой ввод | — (микрофон в поле) | Настройки → Прочее → Голосовой ввод |
| `search` | Поиск | лупа | |
| `admin` | Администрирование | — | пункт меню аватара, заголовок экрана |

Прежние названия, которые больше не пишут: «Речь» (стало «Озвучка»), «Распознавание» как имя раздела (стало
«Сканы»), «Claude Code» как имя раздела (это один из трёх помощников), «Код» (раздел настроек и заголовок push),
«Панель» (администрирование). Выход из учётки — глагол «Выйти»; настройка нижних вкладок телефона — «Нижняя панель».

## Части «Агентов»

| Термин | Значение |
|---|---|
| компьютер | машина владельца с мостом (`agents`); «на связи» / «не на связи» |
| мост, Studio Agent | Windows-приложение `agent/` (`studio-agent`); в окне и трее — «Studio Agent» |
| помощник, агент | Claude, Codex, OpenCode (`engine`); кнопки нового чата на экране «+» — «Claude», «Codex», «OpenCode» |
| проект | подпапка корня проектов моста (`pid`) |
| сессия, чат | сессия CLI (`chat` UUID); вкладка — открытая сессия проекта |
| PIN компьютера | PIN моста (4–8 цифр), отдельный от PIN приложения |
| PIN приложения | PIN учётки для экрана блокировки (4–8 цифр) |
| PIN ссылки | PIN ссылки «Поделиться» (ровно 4 цифры) |
| рабочее место | вкладки проектов, компьютер панели, открытый проект и вид (`workspace`) |

## Настройки

Разделы слева — в порядке реестра: Чат, Фото, Видео, Разговоры, Озвучка, Сканы, Перевод, Защита данных (Cleaner),
Агенты, Прочее (`settings.js::settingsView`, `connection-form.js` `SECTION_NAMES` из `sections-meta.js`). В «Прочем»: голосовой ввод, пароль, блокировка,
сессии, аварийный выход, журнал безопасности, уведомления (push, ntfy), «Интернет» (ключ Exa), часовой пояс,
хранилище, «Удалить всю историю».
