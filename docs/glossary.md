# Глоссарий названий интерфейса

Источник слов для README, страницы входа, manifest, push и текстов разделов. Новый текст берёт название из
столбца «Название»; расхождения ниже — нынешнее состояние кода, их выравнивание — отдельная работа
(запись FINDINGS «Названия и значки разделов расходятся…», идея «Рельс и нижняя панель: «Речь» → «Озвучка»»).

## Приложение

| Где | Сейчас | Файл |
|---|---|---|
| Название | **Студия** (в тексте README — «студия») | — |

| manifest `description` | «Чат, фото и видео» (устарело: разделов восемь) | `app/static/manifest.webmanifest` |
| Вкладка входа | «Студия — вход», заголовок «Студия» | `app/static/login.html` |
| Нет связи | «Студия — нет связи» | `app/static/offline.html` |

## Части «Агентов»

| Термин | Значение |
|---|---|
| компьютер | машина владельца с мостом (`agents`); «на связи» / «не на связи» |
| мост, Studio Agent | Windows-приложение `agent/` (`studio-agent`); в окне и трее — «Studio Agent» |
| помощник, агент | Claude, Codex, OpenCode (`engine`); кнопки нового чата на экране «+» — «Claude», «Codex», «OpenCode» |
| проект | подпапка корня проектов моста (`pid`) |
| сессия, чат | сессия CLI (`chat` UUID); вкладка — открытая сессия проекта |
| PIN компьютера | PIN моста (4–8 цифр), отдельный от PIN приложения |
| PIN приложения | PIN учётки для экрана блокировки (4–8 цифр) |
| PIN ссылки | PIN ссылки «Поделиться» (ровно 4 цифры) |
| рабочее место | вкладки проектов, компьютер панели, открытый проект и вид (`workspace`) |
