# Глоссарий названий интерфейса

Источник слов для README, страницы входа, manifest, push и текстов разделов. Новый текст берёт название из
столбца «Название». В коде имена, значки и порядок разделов — один реестр `app/static/js/sections-meta.js`
(значки — `app/static/js/icons.js`); сервер (`sections.NAMES`, `push.TITLE`) сверяет `tests/test_sections_meta.py`.

Интерфейс поддерживает русский и английский; английские соответствия — `app/static/en.js`.
Русские названия ниже остаются исходными ключами, id и адреса разделов одинаковы для обоих языков.
В английском интерфейсе: Chat · Photos · Video · Speech · Transcription · Scans · Translation · Agents;
служебные экраны — Search · Settings · Administration.

## Разделы

Порядок — группами (на рельсе тонкий разделитель): Чат · Фото, Видео · Озвучка, Расшифровка · Сканы, Перевод · Агенты.
Тот же порядок — в нижней панели телефона (по умолчанию Чат, Фото, Агенты и «Ещё»), в «Поиске», блокировке, выгрузке и
настройках. id раздела и адрес не меняются вместе с именем (`#/speech` — «Озвучка»).

| id (адрес, API) | Название | Значок (`icons.js`) | Где ещё |
|---|---|---|---|
| `chat` | Проекты | облачко | |
| `owui` (`#/owui`, `/api/owui/*`) | Open WebUI | окно с чатом | |
| `code` (`#/code`, `/api/code/*`) | Агенты | приглашение терминала | выгрузка: «Агенты: чаты», «Агенты: подключения» |
| `photo` | Фото | картинка | |
| `video` | Видео | кадр с треугольником | |
| `transcribe` | Расшифровка | звуковая волна | действие в «В работе» — «Расшифровка «…»» |
| `speech` | Озвучка | динамик | действие в «В работе» — «Озвучка · …» |
| `ocr` | Сканы | рамка с строками | действие в «В работе» — «Распознавание «…»» (действие, не имя раздела) |
| `translate` | Перевод | буквы двух языков | |
| `cleaner` | Очистка | щит | ручной перенос запросов и восстановление ответов |
| `dictation` | Голосовой ввод | — (микрофон в поле) | Настройки → Ввод и интернет → Голосовой ввод |
| `search` | Поиск | лупа | |
| `admin` | Администрирование | — | пункт меню аватара, заголовок экрана |

Прежние названия, которые больше не пишут: «Речь» (стало «Озвучка»), «Разговоры» (стало «Расшифровка»), «Распознавание» как имя раздела (стало
«Сканы»), «Claude Code» как имя раздела (это один из четырёх помощников), «Код» (раздел настроек и заголовок push),
«Панель» (администрирование), «Прочее» и «Защита данных» (разделы настроек). Выход из учётки — глагол «Выйти»;
настройка нижних вкладок телефона — «Нижняя панель» (в «Оформлении» и листе «Ещё», не в меню аватара).

## Чат: роли, профили, MCP

| Термин | Значение |
|---|---|
| Роль | именованный текст, который модель получает в начале диалога («Роль в этом диалоге — «Юрист»: …»); чип «Роль» у поля ввода, «Без роли», «Настроить роли»; библиотека — «Настройки» → «Чат» → «Роли», умолчания для новых учёток — «Роли по умолчанию» в «Администрировании» (`roles.py`) |
| Навык | готовое задание с названием: вызывается через «/» в поле ввода «Чата» и «Агентов», над полем — чип «Навык: имя», текст навыка уходит в сообщение, дописанное — уточнением; библиотека учётки — «Настройки» → «Навыки», умолчания для новых учёток — «Навыки по умолчанию» в «Администрировании»; «Навык проекта» — файл `SKILL.md` в папке проекта (`.agents/skills`, `.claude/skills`), пометка «проект» в меню «/» (`skills.py`) |
| По частям | отметка навыка «Чата»: модель получает инструмент, который выполняет каждую часть задачи отдельным запросом; под ответом — шаги «Часть N» (`run_part`) |
| Быстрое действие | навык «Агентов» с отметкой «Кнопкой в пустом чате «Агенты»»: кнопка нового чата до первого сообщения, отправляет текст навыка сразу |
| Профиль подключения | системный текст, параметры запроса (температура, доля вероятностей `top_p`, число кандидатов `top_k`, штраф за повтор тем, предел ответа) и подсказки подключения чата; кнопка «Профиль» у подключения в разделе «Чат»; у общего подключения текст и параметры видит только администратор (`profiles.py`) |
| Согласие на передачу файлов | разрешение передать файлы диалога одному серверу MCP: в ленте «Передать серверу «X» файлы диалога: …?» — «Передать» / «Не передавать»; действует для пары «диалог, сервер», смена адреса или ключа сервера спрашивает снова (`chats.mcp_file_consent`) |
| Медиа диалога | звук и видео, приложенные к диалогу для MCP, который принимает файлы чата; модель видит только имя (`chat_media`) |
| Правила сервера MCP | правила, которые сервер MCP сообщает о своих инструментах (`instructions`); в окне «Инструменты MCP» — свёрнутое «Правила сервера», модель получает их в рамке Studio, ниже слов пользователя и Studio |
| Инструменты MCP | окно кнопки «MCP (n)» у поля ввода: серверы и инструменты этого диалога; общие серверы включены по умолчанию, свои — вручную; метки «интернет» и «с подтверждением» |
| Подтверждение вызова | карточка под ответом, когда инструмент «с подтверждением» ждёт решения: сервер, инструмент, аргументы, «Запустить» / «Отмена»; ответ продолжается в том же сообщении (`chat_pending`) |
| Вопрос модели | карточка под ответом, когда модель спрашивает (`ask_user`): варианты кнопками, своё слово — полем, «Ответить» / «Пропустить» |
| План работы | список шагов, который модель ведёт по ходу ответа: «План: N из M» над текстом; отметки «сделано», «в работе», «впереди» (`messages.todo`) |
| Память | личные заметки о пользователе между диалогами: «Настройки» → «Чат» → «Память», по умолчанию выключена; в ленте — «Память: запись добавлена / удалена» (`memory`) |
| Знания | базы документов для поиска в чате: чип «Знания» у поля ввода, «Настройки» → «Чат» → «Базы знаний», общие — блок «Знания» в «Администрировании»; большое вложение тоже идёт выдержками (`knowledge`) |
| Подсказки | чипы на пустом экране чата: подсказки профиля подключения и серверов MCP; нажатие вставляет текст в поле |
| Заполнение контекста | кольцо у поля ввода открытого диалога, подсказка «Контекст ~N % (x из y)»; оценка, а не проверка |
| Разговор | значок в поле ввода над микрофоном: говорите — модель отвечает голосом, текст остаётся в диалоге |
| Прочитать | кнопка у ответа чата, результата «Перевода» и текста «Сканов»: озвучить новым чатом «Озвучки» |
| Защищённый источник | отметка общего сервера MCP в «Администрировании»: после его вызова в диалоге нет «Интернета» и вызовов с адресами |
| Архив чата | пункт меню «Поделиться» «Скачать архив ZIP с файлами»: переписка с вложениями и файлами результатов |
| Cleaner (своя учётка Cleaner) | прежний вид подключения: адрес Cleaner и личный ключ Cleaner, облачное подключение — в Cleaner; перед отправкой — окно «Что получит модель» (`connections.cleaner`) |
| Через Cleaner | переключатель в меню «⋯» внешнего подключения (чат и перевод): ход идёт через шлюз Cleaner, ключ провайдера остаётся в Studio; у подключения — метка «через Cleaner», у выбора модели диалога — «Cleaner», у ответа — «модель · через Cleaner» (`connections.via_cleaner`) |
| Cleaner для всех внешних моделей | флажок блока «Cleaner» в «Администрировании»: переключатель «Через Cleaner» у внешних подключений включён и заблокирован (`cleaner_route.forced`) |
| Что получила модель | кнопка под ответом через Cleaner: окно с последним запросом хода так, как его получил провайдер, — с заменами; текст хранит Cleaner, не Studio (`messages.cleaner_request`) |

## Служебные экраны (меню аватара)

| Название | Адрес | Что внутри |
|---|---|---|
| Справка | `#/help` | руководство Studio по разделам и руководства серверов MCP (`help.js`) |
| Корзина | `#/trash` | удалённые записи всех разделов 14 дней: «Вернуть», «Удалить навсегда», «Очистить корзину» паролем учётки (`trash.js`) |
| Мои файлы | `#/myfiles` | личная папка на сервере MCP с «Моими файлами»: загрузка, папки, ZIP, корзина сервера, «Ссылка на сутки» — файл без входа по адресу `/f` (`my-files.js`); пункт виден, только если такой сервер есть |

В «Расшифровке» «Записать» открывает запись встречи с микрофона (`recorder.js`). В пустом «Чате» «Скачать ролик» вставляет
запрос на скачивание. Быстрые действия «Агентов» — навыки с отметкой «Кнопкой в пустом чате» в «Настройки» → «Навыки»
(`skills.js`); «Добавить навыки по умолчанию» возвращает начальные действия.

## Части «Агентов»

| Термин | Значение |
|---|---|
| компьютер | машина владельца с мостом (`agents`); «на связи» / «не на связи» |
| мост, Studio Agent | приложение `agent/` (`studio-agent`) для Windows, macOS и Linux; в отказах сервера и моста — только «мост» (не «агент»: агенты — помощники), с нужной версией, где она известна; в окне и трее — «Studio Agent» |
| помощник, агент | Claude, Codex, OpenCode, DeepSeek Harness (`engine`: `claude`, `codex`, `opencode`, `deepseek`); кнопки нового чата на экране «+» — «Claude», «Codex», «OpenCode», «DeepSeek» (полное имя «DeepSeek Harness» — в подсказке кнопки и в остальном интерфейсе) |
| проект | подпапка корня проектов моста (`pid`) |
| сессия, чат | сессия CLI (`chat` UUID); вкладка — открытая сессия проекта |
| PIN компьютера | PIN моста (4–8 цифр), отдельный от PIN приложения |
| PIN приложения | PIN учётки для экрана блокировки (4–8 цифр) |
| PIN ссылки | PIN ссылки «Поделиться» (ровно 4 цифры) |
| рабочее место | вкладки проектов, компьютер панели, открытый проект и вид (`workspace`) |
| зеркало, копия проекта | копия проекта на другом компьютере владельца (`mirror_copies`); кнопка «Зеркало» с цифрой — числом остальных копий; «+ Добавить зеркало», «Сравнить», «Отправить изменения», «Скопировать весь проект», «Отвязать копию» |
| группа копий | все копии одного проекта на компьютерах владельца, равноправные (`mirror_groups`); «Отправить во все копии», «Присоединить» / «Объединить» (папка уже в другой группе), «Постоянные исключения» — общие для группы |

## Настройки

Слева две группы (`settings.js::settingsView`; имена разделов — `connection-form.js` `SECTION_NAMES` из
`sections-meta.js`):

| Группа | Пункт (`#/settings/<id>`) | Что внутри |
|---|---|---|
| Разделы | Чат, Фото, Видео, Озвучка (`speech`), Расшифровка, Сканы, Перевод, Агенты (`code`) — порядок рельса | подключения и модели раздела; у «Чата» — ещё «Профиль» подключения, роли и подключения MCP; у «Агентов» — умолчания чатов, MCP агентов, таймер PIN, компьютеры |
| Разделы | Очистка данных · Cleaner (`cleaner`) | подключения вида «Cleaner (своя учётка Cleaner)» — так же и метка подключения |
| Учётка | Оформление (`appearance`) | тема и акцент (учётка); шрифт, масштаб, плотность, нижняя панель (устройство); часовой пояс |
| Учётка | Навыки (`skills`) | библиотека навыков «Чата» и «Агентов»: создать, изменить, выше и ниже, удалить, «Добавить навыки по умолчанию»; отметки «Кнопкой в пустом чате» и «По частям» |
| Учётка | Защита (`security`) | почта учётки, пароль, блокировка и PIN, ключи устройства, сессии, «Доступы и ссылки», аварийный выход, журнал безопасности |
| Учётка | Уведомления (`notifications`) | push, ntfy |
| Учётка | Данные (`data`) | «Хранилище» (с «Самыми тяжёлыми записями», корзиной и неудачными), выгрузка, «Удалить всю историю» (паролем) |
| Учётка | Ввод и интернет (`input`) | голосовой ввод, «Интернет» (ключ Exa) |
| Учётка | SMTP (`smtp`) — только администратору | почта приглашений, восстановления и кодов входа; «Проверить соединение», «Отправить тестовое письмо себе» |

Прежние адреса перенаправляются: `#/settings/other` → `security`, `#/settings/dictation` → `input`.

## Меню аватара

Имя, логин и версия Studio → «Тема: Авто · Светлая · Тёмная» → шрифт и масштаб этого устройства → «Настройки» →
«Справка» → «Корзина» → «Мои файлы» (при сервере MCP с ними) → «Администрирование» (администратору) → «Выйти».
